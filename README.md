# OKX 實名認證：App 操作流程、證件要求與認證失敗處理方式

搜尋「OKX 實名認證」的人，通常不是想了解一個抽象的 KYC 名詞，而是卡在幾個很實際的問題：要去哪裡認證？需要準備什麼證件？為什麼一直審核失敗？完成認證後可以使用哪些功能？

OKX 的實名認證，本質上就是平台的身份驗證流程。完成身份認證後，帳戶才能解鎖相應的交易、充提幣和 C2C 等功能。未完成認證的帳戶，部分功能會受到限制，不能直接按照一般帳戶方式使用平台。

下面整理 OKX 實名認證的操作步驟、證件拍攝要求、審核時間、常見失敗原因，以及認證後如何選擇交易費率方案。文中涉及地區支援、可用功能和費率的部分，仍應以登入帳戶後顯示的頁面為準，因為 OKX 會依照居住地區、產品類型和帳戶狀態提供不同服務。

## OKX 實名認證是什麼？

OKX 實名認證也常被稱為 KYC，也就是 Know Your Customer。平台會要求用戶提交個人資料、政府簽發的身份證件，以及人臉或自拍驗證，用來確認帳戶由本人操作。

對一般個人帳戶來說，認證通常包括以下幾個部分：

- 選擇實際居住國家或地區
- 填寫姓名、出生日期等基本資料
- 上傳有效身份證件
- 完成人臉識別或自拍驗證
- 視地區和產品需要，提交地址證明或其他資料
- 等待平台審核

OKX 官方說明指出，完成身份認證可以解鎖對應交易權限；尚未完成認證的用戶，可能無法進行充幣、提幣和 C2C 買賣等操作。

需要注意的是，實名認證不是「先隨便填一個地區，之後再改回來」的流程。認證時應使用自己的真實資料，並選擇目前實際居住的國家或地區。若選錯地區或使用他人證件，後續可能出現帳戶資料不一致、功能受限或需要重新提交資料的問題。

## OKX 實名認證怎麼操作？

### App 認證流程

目前較直接的做法是使用 OKX App 完成認證。操作路徑如下：

1. 開啟 OKX App 並登入帳戶。
2. 點擊首頁左上角的個人頭像或帳戶圖示。
3. 進入「帳戶設置」或「個人資料」。
4. 找到「身份認證」。
5. 點擊「立即認證」。
6. 選擇實際居住國家或地區。
7. 按照畫面要求填寫個人資料。
8. 上傳身份證件照片。
9. 完成人臉識別、自拍或視頻認證。
10. 提交資料，等待審核結果。

OKX 官方目前建議，在開始認證前先確認 App 已更新至最新版本。完成更新後，再從「帳戶設置」進入「個人資料」和「身份認證」頁面。

不同地區看到的選單名稱可能略有差異。有些帳戶會直接顯示身份認證，有些帳戶則會先要求確認居住地區，再進入證件上傳頁面。以你登入後實際看到的頁面為準，不需要刻意尋找完全相同的按鈕文字。

### 視頻認證怎麼做？

部分 C2C 或特定服務可能會額外要求視頻認證。官方說明中的操作路徑是進入 App 的「C2C 買幣」，再進入「我的」和「C2C 視頻認證」。

進行視頻認證時，通常需要：

- 開啟手機麥克風和攝影機權限
- 確保環境安靜
- 不要連接耳機
- 依照頁面提示回答問題
- 確認提交前的資料正確

OKX 說明指出，視頻認證時系統會朗讀風險提示，用戶不需要跟讀；在提示音後按照畫面要求回答即可。

## OKX 實名認證需要什麼證件？

可接受的證件會因居住地區和司法管轄區而不同。OKX 顯示的可用證件清單才是判定標準，不能單純按照其他地區的教學照搬。

常見的政府簽發證件包括：

- 身份證
- 護照
- 駕駛執照
- 居留證
- 其他政府簽發的有效身份文件

OKX 的身份證件拍攝指南提到，證件應符合以下條件：

- 仍在有效期內
- 證件上的文字和照片清晰可辨
- 包含出生日期
- 使用證件原件拍攝
- 不使用截圖、影印本或另一張照片
- 證件四個角落盡量完整出現在畫面中
- 需要正反面時，正面和背面都要分別上傳

如果使用護照等沒有背面的文件，通常只需要上傳包含個人資料的照片頁，但是否需要補充其他文件，仍要看認證頁面的具體提示。

### 自拍或手持證件拍攝要求

如果 OKX 要求手持證件自拍，請特別注意以下幾點：

- 手持的證件必須與前面上傳的證件相同
- 證件正面朝向鏡頭
- 保持光線充足
- 證件上的姓名、照片和文字要清楚
- 臉部完整露出
- 不戴口罩、帽子或遮擋臉部的眼鏡
- 手指不要遮住證件內容
- 證件不要遮住臉部

很多認證失敗不是資料本身有問題，而是照片反光、模糊、裁切到證件邊角，或者手機鏡頭沒有對焦。拍攝時不要急著連按下一步，先確認照片能讀清楚再提交，通常比反覆重傳省事。

## OKX 實名認證要多久？

OKX 官方說明表示，視頻審核通常會在提交申請後的 24 小時內完成，但實際時間會受到資料完整度、地區、申請量和是否需要補件影響。審核結果一般會透過消息中心通知。

如果超過預期時間仍沒有結果，可以先檢查：

1. App 內是否出現補件通知。
2. 郵箱或手機是否收到平台訊息。
3. 身份認證頁面是否仍顯示「審核中」。
4. 是否有資料與帳戶註冊資訊不一致。
5. 是否需要提交地址證明或資金來源資料。

若頁面長時間沒有變化，建議從 OKX 幫助中心聯繫線上客服。不要反覆建立新帳戶重新認證，因為同一身份資料關聯多個帳戶，可能讓後續處理更複雜。

## OKX 實名認證失敗的常見原因

### 1. 證件過期或不符合地區要求

使用過期證件、非當地支援的證件類型，或者選擇了錯誤的國家或地區，都可能導致認證失敗。

認證前先確認：

- 居住地區選擇正確
- 證件仍在有效期限
- 證件類型出現在 OKX 頁面提供的選項中
- 姓名和出生日期與提交資料一致

### 2. 證件照片模糊

常見問題包括光線不足、證件反光、照片過度壓縮、證件四角缺失，以及鏡頭對焦在背景而不是證件上。

建議在光線均勻的地方拍攝，避免直接使用強烈閃光燈。證件平放後再拍，通常比手持拍攝更容易保持清晰。

### 3. 自拍與證件不一致

如果自拍中的證件與前面上傳的不是同一份，或者臉部被證件、手指、口罩或帽子遮擋，系統可能無法完成比對。

不要使用他人的證件，也不要讓其他人代替本人完成臉部驗證。這不是可以靠換角度「試到過」的流程，資料不一致時，重試次數越多不一定越快。

### 4. 帳戶資料與證件不一致

註冊時使用的姓名、出生日期或其他資料，如果和證件不同，可能需要先處理帳戶資料更新，再重新提交認證。

OKX 也提醒，帳戶實名認證資料完成後，通常不能直接更改或撤銷。若遇到改名、證件過期或其他個人資料變更，應按照官方更新身份認證資料的流程處理。

### 5. 需要額外認證

部分帳戶在完成基本身份認證後，仍可能被要求進行附加認證。附加認證可能包括：

- 地址證明
- 資金來源證明
- 財富來源證明
- 風險或合規問卷
- 其他與帳戶活動相關的資料

OKX 將附加認證視為進一步確認帳戶資訊和交易活動的流程。若 App 出現「提交信息」或「完成帳戶認證」提示，應依照畫面要求提交資料，而不是只重做一次基本證件認證。

完成認證後，帳戶可用功能會依地區、產品和帳戶等級而不同。一般來說，身份認證是使用以下功能的前置條件之一：

- 充入數位資產
- 提取數位資產
- C2C 買賣
- 現貨交易
- 合約或其他衍生品功能
- 法幣相關服務
- 部分賺幣、借貸或金融產品

這不代表完成 KYC 後所有產品都會自動開放。OKX 官方也明確提示，部分產品可能不適用於所有地區。登入帳戶後顯示的功能和限額，才是對你目前帳戶有效的版本。
